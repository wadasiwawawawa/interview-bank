# 工作面試題庫

個人的面試準備知識庫，用 GitHub Pages 發布。

- **網站**：<https://wadasiwawawawa.github.io/interview-bank/>
- **專案規則**：[`CLAUDE.md`](CLAUDE.md)（AI 與人共同遵守的規則：結構、範本、命名、風格、流程、禁止事項）

## 內容

| 內容 | 資料夾 | 說明 |
|---|---|---|
| 題目卡 | `_questions/` | 一題一檔，分成六大題型：自我介紹、動機、行為題（STAR）、專業題、情境題、反問 |
| 故事素材 | `_stories/` | 用 STAR 寫好的個人經歷，可以被多張題目卡引用 |
| 履歷版本 | `_resumes/` | 主版本隨時間更新，職缺版本針對職缺調整 |
| 面試紀錄 | `_interviews/` | 每場面試後的紀錄，被問到的題目會回填到題庫 |

另外有一個**單字卡練習模式**（`/practice/`）：正面是題目、背面是快速回答；點一下翻面，右滑代表熟了，左滑代表還不熟、下一輪再出現。

## 怎麼新增內容

全部依照 `CLAUDE.md` 第 10 節的流程。跟 AI 說：

- 「幫我加一題：……」→ 新增題目卡
- 「我有一個經歷：……」→ 新增故事素材
- 「今天面試被問了……」→ 新增面試紀錄並回填題庫
- 「我要投這個職缺：……」→ 從主版本履歷建立職缺版本

## 隱私

repo 是公開的。面試官姓名、薪資、未公開資訊、真實公司名稱、個人聯絡方式都不會放進來。含個人資料的原始檔放在 `private/`（已列在 `.gitignore`，不會上傳）。

## 本機預覽

```bash
bundle install
bundle exec jekyll serve
```

開啟 <http://localhost:4000/interview-bank/>。
