這個網站怎麼運作

  1. 題目卡：一題一張，記下題目意圖、回答架構、我的回答，以及給單字卡用的「快速回答」。
  2. 故事素材：用 STAR 寫好的個人經歷，可以被多張題目卡引用。
  3. 履歷版本：主版本隨時間更新，職缺版本針對職缺調整；{% if current_master %}目前使用中的主版本是 {{ current_master.title }}。{% else %}目前還沒有放上履歷。{% endif %}
  4. 面試紀錄：每場面試後回填被問到的題目，讓題庫越用越準。

所有內容都依照 repo 裡的 CLAUDE.md 規則新增，AI 讀過那份文件就能用同一套格式繼續擴充。
